Dorokartes Merchant Profile V3.1
- Softer system typography (removes the sharp/machine Inter look)
- Merchant logo/profile image upload
- JPG/PNG/WEBP, max 3 MB
- Uses Vercel Blob and saves the resulting public URL to Merchant.logoUrl

Required package:
  npm install @vercel/blob@latest

Vercel:
  Connect a Blob store to the Dorokartes project. New Vercel Blob stores use OIDC automatically.
