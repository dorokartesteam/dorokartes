Dorokartes Merchant Portal V4
=============================
Reference-driven redesign matching the approved premium mockup.

Changes:
- premium dark blue sidebar with clean active states
- cleaner typography and consistent hierarchy
- redesigned dashboard hero/current plan card
- redesigned billing page with hero + 3 balanced pricing cards
- proper status pill sizing
- feature icons + right-side checks
- premium banner card styling
- responsive layout

No Stripe/auth/Prisma logic is changed.

Install from project root:
Expand-Archive -Path "$HOME\Downloads\dorokartes-merchant-ui-v4.zip" -DestinationPath "D:\dorokartes" -Force
npm run build
